# Stromobraní

Mobilní aplikace Stromobraní pro Expo / React Native.

## Lokální spuštění

1. Zkopírujte `.env.example` do `.env.local` a doplňte URL API a Mapbox konfiguraci.
2. Nainstalujte závislosti příkazem `npm install`.
3. Spusťte vývojový server příkazem `npm start`.

Veřejná kopie obsahuje pouze klientskou mobilní aplikaci. Serverová a administrační část je vedena odděleně.
